Typing a shortcut
  • Join keys with +: cmd+shift+4, ctrl+alt+t. Separate combos pressed one after another with a space: ctrl+k ctrl+s.
  • Modifiers: ctrl, alt (Option), shift, cmd (Super / Windows key on Linux).
  • Keys: a–z, 0–9, f1–f20, enter, tab, space, backspace, delete, escape, up down left right, home, end, pageup, pagedown, minus, equal, [ ] ; ' , . / ` \, and kp0–kp9 for the number pad.
  • Keys are positions on a US keyboard. On other layouts, record the shortcut instead of typing it.
  • Some shortcuts never reach this page because the system or OpenDeck takes them first (like Cmd+Tab, Cmd+Space or Cmd+Q). Type those instead of recording them.
